## 📌 About the Project

The **Cloud-Based Digital Assurance Framework** is a web-based application for secure file management and digital file integrity.

It helps users **upload, share, edit, verify, and track files** while maintaining their version history and audit records.

The system uses **SHA-256 hashing** to detect changes in file content and provides controlled file sharing with user permissions.

---

## ✨ Key Features

* 🔐 User Registration & Login
* 📁 File Upload and Management
* 🔑 SHA-256 File Integrity Verification
* 👥 File Sharing with Permissions
* ✏️ Controlled File Editing
* 📝 Version History
* 📊 Audit Logs
* ⬇️ Download Tracking
* 🕒 Activity Timestamp Tracking

## 🔄 Working Flow

```text
Login
  ↓
Upload File
  ↓
Generate SHA-256 Hash
  ↓
Share / Edit / Download
  ↓
Create New Version
  ↓
Update Hash
  ↓
Record Audit Log
```
